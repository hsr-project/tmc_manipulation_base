目的
================
* ロボットの運動学モデルを提供する
* ロボットの逆運動学のソルバを提供する．

前提条件
================
* 特になし


IRobotKinematicsModel
=====================
ロボットの運動学のインターフェース．

Tarp3Wrapper
---------------
tarp3のラッパー．ロボットモデルはurdfで記述．

PinocchioWrapper
---------------
pinocchioのラッパー．ロボットモデルはurdfで記述．


IKSolver
=====================
逆運動学のインターフェイス．Chain of responsibilityを用いて解法をカスタマイズ可能．
例: 腕6軸を使った解析解があるのでそのようなリクエストの際は解析解を使用.

NumericIKSolver
---------------
IKSolverの最も基本的な数値IKによる実装．LM法[Sugihara 2009]による．
