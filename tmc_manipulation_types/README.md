`tmc_manipulation_types`
===============================================================================

概要
--------

tmc_manipulation内のパッケージ間のやりとりで利用される構造体，列挙型を定義するパッケージ．

tmc_manipulation外のパッケージとのインタフェースには利用しないことを推奨する．
tmc_manipulation_types_bridgeには，本パッケージで定義している構造体と
ROSインタフェース（メッセージ等）とのコンバータ関数が用意されている．
それらを上手く利用し，上記の推奨を順守してもらいたい．
